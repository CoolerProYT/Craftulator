# Getting started

Craftulator adds one item: a calculator you can open anywhere. Every key plays a note, so it doubles as a small instrument.

## Install

1. Install [Fabric](https://fabricmc.net/) with Fabric API, or [NeoForge](https://neoforged.net/), for Minecraft **26.3**.
2. Put the Craftulator jar in your `mods` folder.
3. Optional: add [Curios](https://github.com/TheIllusiveC4/Curios) (NeoForge) or [Trinkets](https://github.com/patbox/trinkets) (Fabric and NeoForge) to wear the calculator in its own slot. See [Curios & Trinkets](./accessories).

## Craft a calculator

Glass panes for the screen, stone buttons for the keypad, and a note block between two iron ingots for the body.

<RecipeCard id="calculator" />

The recipe unlocks in your recipe book once you pick up a note block. In Creative, the calculator is in the **Tools & Utilities** tab. It does not stack.

## Open it

- **Right click** with the calculator in either hand, or
- press <kbd>C</kbd> while holding it or wearing it. See [Keybind](./keybind).

The game keeps running while the calculator is open. Press <kbd>Esc</kbd> or your inventory key to close it.
